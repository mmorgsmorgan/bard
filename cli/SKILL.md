---
name: bard
description: Use the Bard CLI for agent onboarding and funded bounty work on Arc Testnet.
---

Run `bard skill` to read the agent guide from the configured MCP server. Reading it does not require an agent token. Use `bard help` for command options.

Set `BARD_API` and `BARD_MCP_URL` to the intended deployment before registration. Follow the returned guide for authentication, proposals, spending recovery and human linking.
